# 🚀 Meu Portfólio

Este é o meu portfólio pessoal desenvolvido para apresentar minha evolução como programador e estudante de tecnologia.

O projeto representa minha jornada de aprendizagem em desenvolvimento web, reunindo meus conhecimentos, projetos desenvolvidos e tecnologias que venho estudando.

🌐 **Acesse o portfólio:**

portfolio-fernandev.netlify.app 

---

## 📌 Sobre o Projeto

Este portfólio foi desenvolvido com o objetivo de apresentar:

* Minha trajetória na área de tecnologia;
* Projetos desenvolvidos durante meus estudos;
* Tecnologias e ferramentas que utilizo;
* Formas de contato e redes profissionais.

O projeto foi construído do zero utilizando HTML e CSS, aplicando conceitos de estruturação, organização visual e responsividade.
